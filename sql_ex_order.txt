SQL is written starting with SELECT, but the engine logically processes a query from the source tables outward. The optimizer may change the physical plan; this is the logical order that explains aliases, filters, and grouping.

SQL Execution Logical order
1	FROM
2	WHERE
3	GROUP BY
4	HAVING
5	SELECT 
6	DISTINCT
7	ORDER BY
8	TOP, LIMIT, OFFSET, FETCH

Set operators (UNION, INTERSECT, EXCEPT) run after each side’s SELECT/DISTINCT and before the outer ORDER BY.
